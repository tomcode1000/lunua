Samples

One balance. Two interfaces.

Arc's native gas asset is USDC. The same account balance is exposed as native value at 18 decimals and through the ERC-20 predeploy at 0x3600…0000 at 6 decimals. Contracts written against Ethereum semantics assume two assets. On Arc that assumption produces silent reverts, double-counted balances and broken invariants.

Lunua detects these defects from deployed or undeployed bytecode using live eth_call simulation with state overrides, and reconstructs failed transactions at their original block.

Deploy gate

CLI · CI · AI agents

The engine is a single dependency-free ES module. The CLI exits non-zero on any demonstrated blocking finding and writes Foundry reproductions with --repro, so it gates CI merges and AI-agent deploys. The Lunua agent skill makes a passing run a hard precondition before any Arc deploy.
